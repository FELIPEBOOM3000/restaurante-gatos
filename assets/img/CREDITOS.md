# Créditos de las imágenes

Las fotografías de `gato-1.jpg` a `gato-8.jpg` son imágenes de demostración
descargadas del servicio público [cataas.com](https://cataas.com) (Cat as a
Service). Se incluyen únicamente como marcadores de posición para este proyecto
académico y de portafolio.

Para publicar el sitio como proyecto real se recomienda:

1. Reemplazarlas por fotografía propia del restaurante y de sus gatos.
2. O usar imágenes con licencia explícita (Unsplash, Pexels, etc.) y conservar
   el enlace y el nombre del autor.
3. Optimizar cada imagen a WebP/AVIF y definir textos `alt` descriptivos.

El logo (`logo.svg`) y el favicon (`favicon.svg`) son ilustraciones originales
creadas para Miau Bistró.
